# Local typefaces

Source Sans 3 supplies body text, controls, captions and chart labels. STIX Two Text supplies headings. Both are variable fonts licensed under the SIL Open Font License. Only the normal Latin subsets and Source Sans 3's Greek subset are served.

Sources:

- `@fontsource-variable/source-sans-3` version 5.3.1
- `@fontsource-variable/stix-two-text` version 5.3.0

The licence files beside the fonts include their copyright notices. No external font service is used at runtime.
